# Contributing

Contributions that make the skills sharper in the field are welcome. The bar is the one the skills set for findings: show the work.

## New skills

A new skill belongs in this pack when it covers a repeatable red-team job that is not already covered, and when its workflow can be followed step by step by an agent that has never seen the target. Write it in the same shape as the existing skills: frontmatter with a precise description, a when-to-use section, an ordered workflow, an output format, and hard rules. If a step cannot be acted on, cut it.

## Improvements to existing skills

Ground every change in a case: a target shape where the current workflow missed surface, wasted time, or produced a finding that verification killed. State the case in the pull request description. Changes that only reword prose are not merged.

## Worked examples

An example needs the candidate finding, the verification run with its control, and the verdict. Examples where verification kills the candidate are worth as much as confirmed ones. Use only material you have the right to publish: lab targets, CTF machines, and your own applications. No real client, employer, or third-party target material in any form.

## Authorised use

Everything contributed must be framed for authorised testing: labs, CTFs, and engagements with written permission. Text that assumes an unauthorised target is not accepted.

## Style

Plain prose, short sentences, no filler.
