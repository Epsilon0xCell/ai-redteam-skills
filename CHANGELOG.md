# Changelog

## v0.1.0, 2026-11-12

First release.

- `target-recon` skill: passive-first reconnaissance and attack-surface mapping that ends in a counted surface ledger and scored leads, not a pile of scan output.
- `prompt-injection-testing` skill: direct and indirect prompt-injection testing for LLM applications, with a control case for every probe and a verdict format that separates a real boundary break from a model being agreeable.
- `verification-poc` skill: the proof discipline. A finding is a candidate until a clean, minimal, re-runnable proof confirms it, with a benign control beside it.
- `detection-pairing` skill: every confirmed finding ships with the telemetry that should have caught it: a detection rule sketch, the log fields it needs, and a negative test.
- One worked example: a prompt-injection candidate carried through verification to a confirmed finding with its detection.
- `install.sh` installer for the SKILL.md layout.
